# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Implementation choice under the user's instruction to plan and immediately implement autonomously: React, TypeScript, Vite. No existing files or framework were present.

## Users

Working assumption: organizers of small community tournaments, and portfolio visitors trying a realistic demo.

## Product Purpose

Create tournaments, seed participants, record match scores, and see winners advance through an understandable bracket.

## Capabilities and Constraints

Portfolio application. Implementation scope: single elimination, 2–16 participants, local browser persistence, sample data, read-only share snapshots and JSON export. No accounts, paid services, live collaboration, or server claims.

## Brand Commitments

User requires clean, modern, easy-to-understand UI without generic AI styling. Matchday is an implementation name, not an existing brand.

## Evidence on Hand

Empty workspace at intake. All tournament records are clearly marked sample data.

## Product Principles

Make the next action obvious. Keep the bracket and results consistent. Explain consequences before changing completed results. Let visitors try the product without registration.
